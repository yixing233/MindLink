# MindLink

基于 Wex 改进开发的微信娱乐模块。

## 📦 安装

1. 准备已 root 并安装 LSPosed 的设备。
2. 安装本模块 APK，在 LSPosed 中启用模块，作用域勾选「微信」。
3. 强行停止并重启微信后生效。

## 🔒 隐私与安全

- 本模块不收集、不上传任何个人数据，无统计与埋点。
- 所有配置与自定义图片仅保存在本地存储（/sdcard/Android/media/com.tencent.mm/Mdl/）。
- 除首页日历卡片请求公开黄历接口获取展示数据外无其他网络访问，请求不携带任何用户数据。
- 源码公开，可自行审计。
