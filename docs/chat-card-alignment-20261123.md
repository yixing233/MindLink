# 聊天页悬浮卡片对齐（2026-11-23）

本轮范围为聊天页。以输入卡片的左右边界为基准，对齐分离式顶栏的最外侧卡片。

## 修改

顶栏与输入栏的外侧边距均为 12dp，但原分离式顶栏额外把组件间距加到了返回卡片外侧，
右侧卡片则沿用原生菜单中心。两侧绘制边界因此与输入卡片不一致。

`FloatingHeaderStyle` 现在按顶栏实际宽度定位边缘卡片：返回圆左边缘为 0，
菜单卡片右边缘为顶栏宽度。同步平移原生按钮宿主，点击位置与波纹反馈跟随图标。
组件间距仅保留在卡片之间。关闭分离式样式时恢复宿主原始平移。
多菜单、空菜单、长标题的既有布局规则继续工作。

公告与置顶卡片已经采用顶栏相同的侧边距，本轮保留该规则。
顶栏、输入栏各自的边距设置仍有效。
