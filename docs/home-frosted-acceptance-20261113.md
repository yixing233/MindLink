# 桌面闪退与首页底部遮罩：手动验收

本轮仅修复桌面状态主页与首页悬浮底栏背后的原生遮罩，不以此宣称其它聊天、资料或分组问题已修复。
本地契约/Hook 测试与构建通过，不代替设备验收；当前没有 ADB。

## 安装前

- 使用本轮通过校验的完整候选包；不要把旧公网附件当作这轮新包。
- 直接覆盖安装，保留配置、自定义图片与日志。不要卸载、清数据或清日志。
- 继续在 LSPosed 中启用模块，作用域勾选微信；安装后强行停止并重新打开微信。
- 桌面页读不到宿主日志或配置时显示“未知”，这不是模块未激活的结论，也不需要申请全部文件权限。

## 1. 桌面主页

1. 从桌面冷启动 MindLink，确认主页可进入，无闪退。
2. 点击“复制脱敏诊断”和“Mdl 功能设置”，确认可复制/提示且不闪退。
3. 打开“查看日志”，确认只读显示或明确提示不可读；打开后马上退出、再进入，确认没有过期弹窗或崩溃。
4. 切换深浅主题、旋转屏幕或重新进入，确认状态栏/手势条附近没有内容遮挡，也没有越来越大的安全边距。

## 2. 首页悬浮底栏

1. 悬浮底栏开启时，首页静止观察：胶囊外不应再有整宽原生半透明模糊带。
2. 滚动会话列表、切换四个原生标签，确认胶囊玻璃仍正常，原生标签点击没有失效。
3. 如果开启自动隐藏，向下滚动隐藏胶囊、反向滚动恢复；隐藏期间不应出现旧整宽遮罩。
4. 进入现有聊天，再返回首页；不发送消息，确认首页重新接管遮罩，聊天窗口不被这项底部处理影响。
5. 在微信内关闭悬浮底栏，确认原生栏/原生底部效果恢复；重新开启后胶囊与遮罩处理再次生效。
6. 后台切换再回微信，确认没有遗留遮罩，也不影响原生顶部效果。
